# Data directory

Per-source datasets are generated by the ingestion pipeline and written to
`data/sources/<source_id>/`:

| File | Purpose | Tracked in git |
| --- | --- | --- |
| `products.json` | Structured product dataset (source of truth for the app) | yes (ships empty) |
| `products.xlsx` | Products / Ingredients / Categories / Metadata sheets | generated |
| `embeddings.json` | Cached embeddings keyed by product_id + content hash | no (git-ignored) |
| `ingestion_report.json` | Ingestion counts and status | generated |

This repository ships **without ingested data**. The included
`abc-pharma-catalog/products.json` is an empty placeholder.

To populate it, configure a real source in [`sources/sources.json`](../../sources/sources.json)
and run:

```powershell
python scripts/ingest.py
```

See [docs/ingestion.md](../../docs/ingestion.md) for details.
